Цели проекта

Разработка интеллектуальной системы для анализа и оценки потенциальной обитаемости экзопланет на основе их физических параметров.

Создание удобного интерфейса для визуализации и исследования данных об экзопланетах.

Возможности системы

• Анализ физических параметров экзопланет

• Расчет индекса подобия Земле (ESI)

• Визуализация данных в реальном времени

• Интеграция с NASA APOD API
