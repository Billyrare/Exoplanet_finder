# Северное сияние (Aurora Borealis) для ExoPlanet Analyzer

## Описание
Этот эффект создает анимацию северного сияния (Aurora Borealis) для главного меню и заголовков сайта ExoPlanet Analyzer. Эффект основан на CSS и JavaScript без использования тяжелых библиотек.

## Файлы
- `aurora.css` - Стили для визуального эффекта 
- `aurora.js` - JavaScript код для инициализации и управления эффектом

## Возможности
- Плавное анимированное северное сияние с несколькими слоями
- Реагирует на движение мыши (параллакс-эффект)
- Изменяется при прокрутке страницы
- Интеграция со звездным фоном
- Адаптивный дизайн для мобильных устройств

## Настройка эффекта

### Цвета
Цвета настраиваются в CSS-переменных в начале файла `aurora.css`:

```css
:root {
  --aurora-color-1: rgba(120, 200, 255, 0.4); /* Светло-синий */
  --aurora-color-2: rgba(50, 180, 255, 0.3);  /* Средне-синий */
  --aurora-color-3: rgba(100, 230, 180, 0.25); /* Бирюзовый */
  --aurora-color-4: rgba(160, 140, 240, 0.3); /* Фиолетовый */
  --aurora-color-5: rgba(100, 220, 255, 0.25); /* Голубой */
  
  /* Дополнительные цвета для космической темы */
  --aurora-glow: rgba(0, 210, 255, 0.15);
  --star-color: rgba(255, 255, 255, 0.8);
  --flare-color: rgba(180, 230, 255, 0.4);
}
```

### Скорость анимации
Скорость движения полос сияния можно изменить, отредактировав значения `animation-duration` для каждой полосы в файле `aurora.css`.

### Интенсивность эффекта
Интенсивность эффекта можно настроить, изменив:
1. Значения `opacity` для каждой полосы
2. Интенсивность размытия (`filter: blur()`)
3. Количество полос (по умолчанию 5)

## Добавление на новые страницы

Чтобы добавить эффект на новую страницу, включите в `<head>` следующий код:

```html
<link rel="stylesheet" href="aurora.css">
<script src="aurora.js"></script>
```

И убедитесь, что у вас есть элементы `.navbar` и `.hero-section` или добавьте нужные селекторы в файл `aurora.js`.

## Модификация JavaScript

В файле `aurora.js` вы можете настроить:
- Селекторы элементов, к которым применяется эффект
- Количество создаваемых полос сияния
- Интенсивность параллакс-эффекта
- Реакцию на прокрутку
- Количество и поведение звездных вспышек
