## Описание проекта
Веб-приложение для анализа и выявления потенциально обитаемых экзопланет на основе их физических характеристик (радиус, температура, плотность) с использованием методов машинного обучения и обширных научных данных.

Система позволяет:
- Анализировать характеристики экзопланет и оценивать их потенциальную обитаемость
- Сравнивать новые экзопланеты с существующими в базе данных, используя реальные научные каталоги
- Визуализировать параметры планет и их потенциал обитаемости
- Предсказывать индекс схожести с Землей (ESI) и вероятность обитаемости
- Сохранять результаты анализа

## Функциональность

### Анализ экзопланет с применением машинного обучения
Система объединяет несколько подходов для оценки обитаемости:
1. Расчет **индекса обитаемости** (0-100) на основе отклонений от земных параметров
2. Предсказание **индекса схожести с Землей (ESI)** с помощью модели KNN, обученной на данных из каталога потенциально обитаемых миров
3. Классификация экзопланет на **потенциально обитаемые/необитаемые** с использованием модели Random Forest

### Расширенный анализ экзопланет
Система включает дополнительные функции для глубокого исследования экзопланет:
1. **Моделирование атмосферы** - расчет вероятного состава атмосферы (азот, кислород, аргон, CO2) на основе физических параметров
2. **Оценка водного потенциала** - определение вероятности наличия жидкой воды
3. **Анализ пригодности для различных форм жизни** - оценка условий для микроорганизмов, растений, простых и сложных форм жизни
4. **Моделирование магнитного поля** - расчет параметров магнитного поля и уровня защиты от радиации

### Сравнительный анализ на реальных данных
Система находит наиболее похожие экзопланеты, используя:
- Каталог подтвержденных экзопланет NASA (500+ объектов)
- Каталог потенциально обитаемых миров (70+ объектов)
- Взвешенное евклидово расстояние между параметрами планет

### Визуализация
Каждая планета визуализируется с учетом ее параметров:
- Размер отражает радиус планеты
- Цвет зависит от температуры (от холодных синих до горячих красных оттенков)
- Текстура меняется в зависимости от плотности

### База данных экзопланет
В системе содержатся следующие данные:
- Датасет подтвержденных экзопланет NASA
- Каталог потенциально обитаемых миров с индексами ESI

## Использование
1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите Flask сервер: `python app.py`
3. Откройте http://localhost:5000 в браузере
4. Введите параметры экзопланеты (название, радиус, температура, плотность)
5. Нажмите кнопку "Анализировать"
6. Система отобразит:
   - Индекс обитаемости
   - Предсказанный индекс схожести с Землей (ESI)
   - Вероятность обитаемости
   - Визуализацию планеты
   - Состав атмосферы и вероятность наличия жидкой воды
   - Оценку магнитного поля и защиты от радиации
   - Список похожих планет из реальных научных каталогов
7. При желании сохраните результат, нажав "Сохранить результаты"

## Модели машинного обучения

### KNN Регрессор для предсказания ESI
Модель обучена на данных каталога потенциально обитаемых миров и предсказывает индекс схожести с Землей (Earth Similarity Index) - метрику от 0 до 1, где 1 означает полное соответствие земным условиям.

### Random Forest для классификации обитаемости
Классификатор случайного леса определяет, является ли планета потенциально обитаемой, на основе ее физических параметров.

## Методология расчета обитаемости
Индекс обитаемости (0-100) рассчитывается на основе:
- Радиус (30% веса) - идеальное значение: 1.0 R⊕ (земной радиус)
- Температура (40% веса) - идеальное значение: 288K (средняя температура Земли)
- Плотность (30% веса) - идеальное значение: 5.51 г/см³ (плотность Земли)

Оценка обитаемости:
- 80-100: Высокий потенциал обитаемости
- 60-79: Средний потенциал обитаемости
- 40-59: Низкий потенциал обитаемости
- 20-39: Очень низкий потенциал обитаемости
- 0-19: Непригодна для жизни

## API сервера

### 1. POST /api/analyze
Анализирует параметры экзопланеты и оценивает ее потенциальную обитаемость.
Возвращает как базовый, так и расширенный анализ.

### 2. POST /api/advanced_analyze
Расширенный анализ экзопланеты с детальной информацией об атмосфере, магнитном поле и пригодности для различных форм жизни.

### 3. GET /api/exoplanets
Возвращает список экзопланет для отображения в интерфейсе, генерируемый на основе данных из CSV-файлов.

### 4. GET /api/dataset/confirmed
Возвращает данные из датасета подтвержденных экзопланет с поддержкой пагинации.

### 5. GET /api/dataset/habitable
Возвращает данные из каталога потенциально обитаемых миров.
