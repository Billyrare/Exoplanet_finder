# Инструкция по запуску системы анализа экзопланет

## Установка необходимых зависимостей

Для работы системы необходимо установить Python 3.7 или новее и следующие библиотеки:

```bash
pip install -r requirements.txt
```

## Запуск веб-приложения

### Локальный запуск для разработки

```bash
python app.py
```

Приложение будет доступно по адресу [http://localhost:5000](http://localhost:5000)

### Запуск на сервере

Для запуска на сервере рекомендуется использовать Gunicorn:

```bash
gunicorn -w 4 -b 0.0.0.0:5000 app:app
```

## API Endpoints

### 1. GET /

Возвращает основную HTML-страницу приложения.

### 2. POST /api/analyze

Анализирует параметры экзопланеты и оценивает ее потенциальную обитаемость.

**Параметры запроса:**
```json
{
    "name": "Название планеты",
    "radius": 1.5,      // Радиус в радиусах Земли
    "temperature": 280, // Температура в Кельвинах
    "density": 5.2      // Плотность в г/см³
}
```

**Пример ответа:**
```json
{
    "name": "Название планеты",
    "radius": 1.5,
    "temperature": 280,
    "density": 5.2,
    "mass_earth": 17.06,
    "predicted_esi": 0.85,
    "habitability_probability": 72.5,
    "is_potentially_habitable": true,
    "habitability_score": 78,
    "similar_planets": [
        {
            "name": "Kepler-442b",
            "radius": 1.34,
            "temperature": 233,
            "distance": 0.12,
            "similarity_percentage": 88.0,
            "source": "NASA Confirmed Exoplanets"
        },
        // ...
    ],
    "assessment": "Высокий потенциал обитаемости. Планета имеет характеристики, близкие к земным, и находится в 'зоне Златовласки'. Индекс подобия Земле (ESI) очень высокий (0.85), что указывает на значительное сходство с Землей."
}
```

### 3. GET /api/exoplanets

Возвращает список экзопланет для отображения в интерфейсе, генерируемый на основе данных из CSV-файлов.

### 4. GET /api/dataset/confirmed

Возвращает данные из датасета подтвержденных экзопланет с поддержкой пагинации.

**Параметры запроса:**
- `page`: номер страницы (по умолчанию 1)
- `per_page`: количество записей на странице (по умолчанию 50)

### 5. GET /api/dataset/habitable

Возвращает данные из каталога потенциально обитаемых миров.

## Модели машинного обучения

В системе используются две модели машинного обучения:

1. **KNN Регрессор** - предсказывает индекс схожести с Землей (ESI) на основе физических параметров планеты
2. **Random Forest Classifier** - классифицирует экзопланеты на потенциально обитаемые и необитаемые

## Решение проблем

### Ошибка при загрузке датасетов

Если возникает ошибка при загрузке датасетов, убедитесь, что файлы находятся в директории `data/` и имеют правильный формат.

### Ошибка при запуске сервера

Если сервер не запускается, проверьте:
1. Установлены ли все зависимости из `requirements.txt`
2. Правильно ли указаны пути к файлам данных
3. Нет ли конфликтов портов (по умолчанию используется порт 5000)
